## Boundaries observed

- The port's render images are never embedded; the crane count read from them is carried as a fact with this attribution.
- No passage from any source is copied verbatim; every fixture string is a paraphrase with its source named in the item's note.
- Real organisation names (Helsingborgs Hamn AB, City of Helsingborg, Kemira AB, Trafikverket, Mark- och miljödomstolen, Actemium, Interlink) and place/facility names (Västhamnen, Södra hamnläget, Gåsebäck, Planteringen, Öresund, kaj 904, Interlink Logistik Kombiterminal) appear under the rule-7 exception, each attributed where the fixture discloses it.
- Domain terminology (containerterminal, kaj, muddring, kombiterminal, landström/OPS, aRTG, STS-kran, feeders, Post-Panamax) is the demo's subject, in both interface languages.
